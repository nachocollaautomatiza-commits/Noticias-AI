MCP + A2A: Los protocolos abiertos que estandarizan la comunicación entre agentes

El ecosistema multi-agente converge en dos estándares: MCP (Model Context Protocol) para conectar agentes con herramientas externas, y A2A (Agent-to-Agent) para comunicación entre agentes de distintos vendors. A2A define Agent Cards para descubrimiento, lifecycle de Tasks para estados, y skills con OAuth para autorización. Esto habilita sistemas donde un agente Claude coordina sub-agentes Hermes o Gemini según especialización. Relevante ahora

El 73% de líderes en finanzas planea desplegar plataformas de orquestación en los próximos 18 meses.
